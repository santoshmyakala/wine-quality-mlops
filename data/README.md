# Data

`raw/winequality_red.csv` and `raw/winequality_white.csv` are the **Wine Quality** dataset from the UCI Machine Learning Repository, redistributed unchanged under its **CC BY 4.0** licence.

> P. Cortez, A. Cerdeira, F. Almeida, T. Matos and J. Reis. *Modeling wine preferences by data mining from physicochemical properties.* Decision Support Systems, 47(4):547–553, 2009. https://doi.org/10.24432/C56S3T

| File | Rows | Features | Target |
|---|---|---|---|
| `winequality_red.csv` | 1,599 | 11 physicochemical measurements | `quality` (0–10, observed 3–8) |
| `winequality_white.csv` | 4,898 | 11 physicochemical measurements | `quality` (0–10, observed 3–9) |

`processed/` is generated by `dvc repro` and is not committed.
